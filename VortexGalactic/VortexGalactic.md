# VortexGalactic
Vortex Galactic is a specialized non-general purpose Web Extension for the Platform Vortex, meaning it only focuses on improving the navbar, it is compatible with BetterVortex currently.

# What does it add?
- BETTER NAVBAR!

# Discontinuation
On July 4th 2026, VortexGalactic extension will no longer be updated and no longer receive any support. the extension will be merged with BetterVortex by then.
