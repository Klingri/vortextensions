# VortexUltra
Vortex Ultra is a specialized non-general purpose Web Extension for the Platform Vortex, meaning it only focuses on improving the profiles, it is compatible with BetterVortex currently.

# What does it add?
- BETTER PROFILES!

# Discontinuation
On July 4th 2026, VortexUltra extension will no longer be updated and no longer receive any support. the extension will be merged with BetterVortex by then.
